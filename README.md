## 📖 About

This project was created as part of a **university course project**. The goal is to build a system that can look at a picture of a water bottle and detect **how full it is**.

### 📸 Current Stage: Dataset Collection

We are building our own dataset by photographing the bottles provided by our professor.

- 🍶 **4 different bottles**
- 💡 **Different lighting conditions**
- 🌊 **Different fill levels**

Capturing this variety helps the model work reliably in real-world conditions.
